# 网页图片和视频下载

在电脑上用 Chrome 或 Microsoft Edge 浏览网页时，可以找出网页里的图片和可直接下载的视频，勾选后保存。

## 第一步：下载并解压

1. 点开[扩展下载页](release/网页图片和视频下载.zip)，再点右上角的“下载原始文件”（向下箭头，英文可能显示为“Download raw file”）。
2. 打开电脑的“下载”文件夹，右键点“网页图片和视频下载.zip”。在 Windows 上点“全部解压缩”→“提取”；在 Mac 上双击压缩包即可解压。
3. 打开解压后的文件夹，找到里面的“网页图片和视频下载”文件夹。下一步要选中的是这个文件夹，不是压缩包，也不是文件夹里的某个文件。

## 第二步：安装（选你用的浏览器）

**Chrome**

1. 在地址栏输入 `chrome://extensions`，按回车键。
2. 打开右上角的“开发者模式”。
3. 点左上角的“加载已解压的扩展程序”。
4. 选中刚解压的“网页图片和视频下载”文件夹，再点“选择文件夹”（Mac 上点“选择”）。
5. 点浏览器右上角拼图形状的“扩展程序”按钮，在“网页图片和视频下载”旁点图钉。如果没看到图钉，点旁边的三个点，再点“固定到工具栏”。

**Microsoft Edge**

1. 在地址栏输入 `edge://extensions`，按回车键。
2. 打开左侧的“开发人员模式”。如果左侧菜单没有展开，先点左上角的菜单按钮。
3. 点“加载解压缩的扩展”（有的版本叫“加载已解压的扩展程序”）。
4. 选中刚解压的“网页图片和视频下载”文件夹，再点“选择文件夹”（Mac 上点“选择”）。
5. 点浏览器右上角拼图形状的“扩展”按钮，在“网页图片和视频下载”旁点眼睛图标“在工具栏中显示”。如果没有眼睛图标，点旁边的三个点，再点“在工具栏中显示”。

请保留解压后的文件夹，不要移动或删除。浏览器如果提示你关闭开发者模式，想继续使用这个扩展时不用关闭它。

## 怎么用

1. 打开你想保存图片或视频的网页，点工具栏上的扩展图标。它会自动扫描；如果漏了下面才出现的图片，先把网页往下滚动，再打开扩展点“重新扫描”。
2. 可选“图片”或“视频”，也可以按宽高设置最小尺寸。尺寸不明的文件只在选择“不限”时显示。
3. 勾选想要的内容，或点“全选”选中当前列表里的所有项目，再点“下载所选”。也可以直接在网页上右键点图片或视频，再点“下载这张图片”或“下载这个视频”。
4. 点浏览器右上角三个点 →“下载内容”或“下载”，可以看下载进度和结果。文件通常保存在电脑的“下载”文件夹；如果浏览器问你存哪里，选好位置并点“保存”。

## 哪些内容不能下？

- 可以下载网页上的普通图片和直接提供的视频文件。像 YouTube、哔哩哔哩、抖音等网站经常把视频分成很多小段播放，这类流式视频不能直接下载；能识别时，扩展会显示提示。扩展不会绕过付费、加密或版权保护。
- 浏览器设置页、扩展商店和一些来自其他网站的内嵌内容不能扫描。部分网站也可能不允许下载文件或预览图片。
- 请只下载你有权保存的内容。扩展不需要账号，不会把扫描结果上传到服务器。
